# PhotoStudio Web

一个运行在浏览器中的 Photoshop 风格图像编辑器。纯前端实现（原生 JavaScript + Canvas 2D），所有图像处理都在本地完成。

## 快速开始

```bash
npm install
npm run dev      # 开发模式，打开 http://localhost:5173
npm run build    # 生产构建，输出到 dist/
npm run preview  # 预览生产构建
```

## 项目结构

```
src/
  core/        文档模型、图层、选区、历史记录（写时复制快照）、合成器、文档操作
  filters/     像素算法与滤镜/调整的声明式定义（对话框由定义自动生成）
  tools/       各工具实现（统一的 onDown/onMove/onUp/drawOverlay 接口）
  view/        画布视口：缩放平移、渲染、标尺、输入分发
  ui/          菜单、工具栏、选项栏、面板、对话框、拾色器
  io/          新建/打开/存储/导出、示例文档
  commands.js  命令注册表（菜单与快捷键共用）
  keyboard.js  全局快捷键
scripts/gen-icons.mjs  按需生成 Lucide 图标注册表（新增图标后运行 npm run icons）
```

### 设计要点

- **历史记录**：快照只保存图层画布的引用，被快照引用的画布会被“冻结”，下一次修改前自动复制（写时复制），因此每一步只占用实际改变的图层的内存。
- **实时预览**：工具和滤镜通过 `doc.preview` 临时替换某个图层的像素，合成器在每帧渲染时使用预览，确认后才写入图层并记录历史。
- **画笔引擎**：笔触先累积在独立的缓冲区，再按工具不透明度合成到图层，因此同一笔内的重叠不会叠加加深（与 Photoshop 一致）。
